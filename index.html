A quiet reader for Markdown, PDF, spreadsheets and JSON. Open files from your disk or a public link, read several side by side, and keep a note from anything you select. A PDF or an .xlsx becomes a document you can read and annotate like any other; a .json opens as a tree, a table, a graph or coloured source.

            Getting started

            Everything you open is kept in this browser so it's here next time — nothing is uploaded anywhere. Drop a .md, .pdf, .xlsx or .csv file anywhere on the window, or paste a link to one (a raw.githubusercontent.com URL, a Gist, or any server that allows cross-origin reads). A PDF is read for its text, so it can be searched, quoted and noted like anything else — a scan with no text in it has nothing to read. In the reading view, select text and choose Save as note to bookmark a passage — notes remember where they came from and jump you straight back. A .json file opens in the JSON view instead: a collapsible tree, a table of any array of records, coloured source, and an edit pane that tells you which line broke. JSON that arrived inside a string is recognised and opens like the document it is.

            Select text to save a note — or press ⌘⇧S

            Notes

            No notes yet — there are two ways to make one.

            Write one here. A title, Markdown, and any images you paste, drop or pick. It belongs to no document and stays in this browser with everything else.

            Or keep a passage. In the reading view, select any text and choose Save as note — it remembers where it came from and takes you back.

            An empty canvas

            Press R for a rectangle, C for a circle, A for an arrow, then drag. F draws a container — anything you put inside travels with it.

            Shapes line up with each other as you drag them. Press ? for every shortcut. Every object takes text: double-click it, or select it and press Enter. Select a shape and drag a side dot to pull out an arrow that stays attached. N gives a text box with no visible edge. ⌘C/⌘V copies and pastes, corners resize, space-drag pans, shift keeps things square.

            Compare two files
            
          
            Upload them, paste them, download them from a URL, or take two things already in your
             library. Source, JSON, CSV, prose — Folio works out what they are and matches them up
             accordingly.
            
          
            JSON is compared key by key, so a reordered field is not a change and a
             record that only changed place is reported as moved. CSV is compared row
             by row and column by column. Everything else is compared line by line, anchored on the
             rarest shared lines so that a moved function reads as a moved function rather than as a
             wall of red and green — and then word by word inside each rewritten line.
