        Getting started

        Everything you open is kept in this browser so it's here next time — nothing is uploaded anywhere. Drop a .md file anywhere on the window, or paste a link to a raw Markdown file (a raw.githubusercontent.com URL, a Gist, or any server that allows cross-origin reads). In the reading view, select text and choose Save as note to bookmark a passage — notes remember where they came from and jump you straight back.

        Select text to save a note — or press ⌘⇧S

        An empty canvas

        Press R for a rectangle, C for a circle, A for an arrow, then drag. F draws a container — anything you put inside travels with it.

        Shapes line up with each other as you drag them. Press ? for every shortcut. Every object takes text: double-click it, or select it and press Enter. Select a shape and drag a side dot to pull out an arrow that stays attached. N gives a text box with no visible edge. ⌘C/⌘V copies and pastes, corners resize, space-drag pans, shift keeps things square.

        Open from URL

        A direct link to a Markdown file. Folio downloads it into this browser and renders it.

        GitHub /blob/ links are converted to their raw form automatically. The server must allow cross-origin reads (Access-Control-Allow-Origin) — raw.githubusercontent.com, Gists, and GitHub Pages do.
